# EMI Calcora - Advanced Financial Calculator

> **🔗 Live Link:** [calcora.in](https://calcora.in)

EMI Calcora is a modern, comprehensive suite of financial calculators built for professional financial planning. It provides a clean, responsive, and intuitive interface for complex financial calculations, helping users make informed decisions about loans, investments, and taxes.

## Features

- **Loan & EMI Calculator**: Calculate monthly installments, total interest, and visualize the amortization schedule.
- **Investment Planning**:
  - **SIP Calculator**: Plan mutual fund investments with estimated returns.
  - **FD Calculator**: Calculate Fixed Deposit maturity amounts.
  - **PPF Calculator**: Plan long-term tax-saving investments in Public Provident Fund.
- **Retirement Planning**: Estimate required retirement corpus, future monthly expenses adjusted for inflation, and required monthly savings.
- **Advanced Loan Tools**:
  - **Loan Eligibility**: Calculate maximum loan amount based on income and existing obligations.
  - **EMI vs Prepayment Simulator**: Visualize the impact of extra payments on loan tenure and interest saved.
- **General Calculators**:
  - **Simple & Compound Interest**: Flexible interest calculations.
  - **GST Calculator**: Quickly add or remove GST from amounts.

## Tech Stack

- **Framework**: [Next.js 15](https://nextjs.org/) (App Router)
- **Library**: [React 19](https://react.dev/)
- **Styling**: [Tailwind CSS v4](https://tailwindcss.com/)
- **Charts**: [Recharts](https://recharts.org/)
- **Icons**: [Lucide React](https://lucide.dev/)
- **Animations**: [Motion](https://motion.dev/)
